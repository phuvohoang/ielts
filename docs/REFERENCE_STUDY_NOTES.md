# Reference study notes

Study date:2026-11-23. These are editorial notes for original teaching content, not an ingestion pipeline or a database of textbook material. Source PDFs remain unchanged outside the repository. Local OCR/renders were temporary reading aids and are not part of the application.

## Grammar for IELTS with Answers

All 272 PDFpages were studied:25 unit presentations, context/exercise/test-practice material, keys, scripts and appendices. Ambiguous OCR onPDF 191/249/269/271 was checked in rendered pages. A supplied audio recording was not available; script reading is not audio verification. Fine visual details of every chart were not quantitatively audited.

Observed sequence: present/past/perfect/future aspect → noun countability/articles/reference → modifiers/comparison/noun phrases → modals/reporting/verb patterns → conditions/prepositions/relatives → organisation/passive/linking/stance/nominalisation. Units use context first, explanation with examples, controlled grammar production and IELTS-style application. The original book mixes Academic and General tasks, so its graph tasks should not become the General letter pathway.

Content safeguards from actual reading: simple/continuous depends on intended meaning, not a universal list of time words; stative verbs can have dynamic senses; correct tense changes can still alter meaning. A key onPDF 249 incorrectly labels where in a locative relative clause as an object; do not reproduce that label. Some organisation advice expresses naturalness preferences, not absolute grammatical prohibitions. Old factual claims and projections are not current evidence.

## Cambridge Vocabulary for IELTS Advanced

All 177 OCRpage files were examined and surviving text studied, including 20 topic units,5 reference/skill units, cumulative tests, keys, scripts and wordlist. WordlistPDF 171–175 and selected problematic pages were visually checked. Important source defects: printed 72–73(opening rural-life section ofUnit 13) are absent; PDF 118 and 136 both duplicate printed 128(Unit 25 Speaking). Missing text was not invented. No supplied audio was listened to, and phonemic symbols in the scan are not a verified pronunciation recording.

Actual topic progression spans people, time/change, community, science, study/work, advertising, travel, government, conservation, space, technology, consumerism, urban life, problems/solutions, natural phenomena, energy, business/finance, crime, media and arts. Strategy units teach dictionary entries, meaning in context, word families, paraphrase/reference, listening/speaking and writing precision. The source targets advanced/Academic learners. The adapted track prioritizes practical GT contexts and a small productive vocabulary, with technical words marked receptive/optional. Do not reuse the book's simplified synonyms as universal equivalents; claim/fact, evidence/proof, charged with/convicted of and efficient/effective need semantic context.

## English Collocations in Use Intermediate

All 193 text-bearing pages studied:60 presentations,60 exercise pages, completekey/index andfrontmatter. PDF 2 was rendered and confirmed genuinely blank. Column/table extraction can interleave lines; exact-choice questions require a visual check before using them as a conceptual reference.

The first 5 units teach noticing, dictionary use, recording, types and register; the source then permits topic order to follow learner needs. Presentation includes mini-texts, dialogues, tables and meaning contrasts. Exercises cover matching, contextual cloze, collocation/error work, meaningful rewriting, register classification and personal use. Keys explicitly admit other possible answers. Unit 23 includes a dialogue with no errors, followed by a naturalness/variety rewrite; do not relabel such tasks as grammatical correction.

Important accepted-variant cautions: enrol on/in a course; take/sit an exam; have/take a break; make/take a decision; conduct/carry out/do research; raise/bring up children. Register and context matter. Naturalness advice is not a blanket grammar ban. Dramatic newspaper/literary combinations should not displace clear practical language in letters.
